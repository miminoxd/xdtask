# Telegram-бот для бронирования активностей туристической базы

Бот позволяет гостям бронировать активности:
- 🎣 Рыбалка
- 🥾 Поход
- ⛷ Лыжи

## Возможности
- Диалог бронирования через `/start`
- Валидация даты, времени и телефона
- Подтверждение и сохранение брони в SQLite
- Просмотр последних бронирований пользователя через `/my_bookings`
- Отмена диалога через `/cancel`

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Установите переменную окружения:
   ```bash
   export BOT_TOKEN="ваш_токен"
   ```
4. Запустите:
   ```bash
   python bot.py
   ```

По умолчанию бронирования сохраняются в `bookings.db` в текущей директории.
Можно задать путь к базе через `DB_PATH`.
